# Canvas 背景特效系统设计

- **日期**：2026-06-02
- **项目**：Personal-site（simmzl.cn · GitHub Pages 纯静态部署）
- **分支**：`feat/canvas-bgfx`
- **状态**：已与用户对齐，待审阅 → 实施计划

---

## 1. 背景

沃伊特-坎普夫测试的 6 道题各有一个背景氛围特效（星空 / 铁轨 / 声波 / 黄昏 / 雨 / 月），当前用**纯 CSS** 实现（`#bgfx.fx-*::before/::after` + 渐变 + `@keyframes`，见 `assets/style.css:174-236`）。

问题：
- **视觉机械/假**：CSS 渐变本质是"重复贴图整体平移"，雨太规则、星空像贴图、缺乏自然随机与深度
- **无法交互**：CSS 做不到鼠标视差、粒子斥力、点击响应

改用**手写 canvas 粒子引擎**，逐题粒子化重做，并加入鼠标交互。

## 2. 目标 / 非目标

**目标**
- 手写统一 canvas 引擎（**零依赖**），6 个效果**全部**粒子化重做
- 三种交互：**鼠标视差/景深 + 鼠标斥力/扰动 + 点击波纹/爆发**（全要）
- 保持**一题一主题** + **monochrome 随题变色**（绿→红→蓝→橙→蓝→银）
- 保持**零构建、零依赖、纯静态**

**非目标（明确不做）**
- ❌ 不引入粒子库（tsParticles 等）/ WebGL / three.js / 构建工具
- ❌ 不改测试题目、流程、其它 UI / CRT 视觉
- ❌ 不破坏现有模块化结构（terminal/quiz/cli/bgm）

## 3. 关键决策（与用户对齐）

| 决策 | 选择 |
|------|------|
| 范围 | 6 个全部重做（统一引擎） |
| 实现 | 手写 canvas（方案 A），非库 / 非 WebGL |
| 交互 | 视差 + 斥力 + 点击波纹，三者全要 |
| 约束 | 保持一题一主题、随题变色、零构建零依赖、性能底线 |

## 4. 引擎架构（`assets/js/bgfx.js`）

一个全屏 `<canvas id="bgfx">`（替换现有空 `<div id="bgfx">`）+ 单个 RAF 主循环 + 可切换效果模块。

**对外接口**
```
BGFX.init(canvas)                      // 取 ctx、resize 监听、绑定鼠标/触摸/点击、启动 RAF
BGFX.setEffect(name, palette, tension) // 切题调用：切效果 + 传配色 + 强度(0~1)
BGFX.reset()                           // 前奏/判定时回基线（停粒子、清屏）
```

**主循环（每帧）**：清屏 → `effect.update(dt, env)` → `effect.draw(ctx, env)`

**`env` 对象**：`{ color, dim, pointer:{x,y}, ripples:[], tension, w, h, dpr }`

**效果模块**：6 个独立小模块，统一实现 `{ init(w,h), update(dt, env), draw(ctx, env) }`，各几十行。

**共享设施**：粒子对象池（复用、防 GC）、统一交互层、统一配色与过渡。

## 5. 六个效果的视觉设计（粒子化重做）

### Q1 星空 `stars`（绿）
- **粒子**：远/中/近**三层**星点（数量递减、尺寸递增），各自缓慢漂移 + 独立闪烁（亮度脉动）
- **视差**：三层按深度系数随鼠标偏移（近层动得多）→ 真实景深
- **斥力**：鼠标附近星点轻微避让
- **点击**：该处星点爆开一圈

### Q2 铁轨 `tracks`（红）
- **画面**：单点**透视**，枕木从消失点由远及近、由小变大滚向观察者（无限逼近感），两条轨道线收束于消失点；红色警报呼吸
- **视差**：消失点随鼠标横移（轨道朝鼠标方向延伸）
- **点击**：一道脉冲沿轨道从远处冲来

### Q3 声波 `waves`（蓝）
- **画面**：中心持续发出同心圆环（扩散 + 淡出）
- **点击**：在点击处激发一圈新声波（**最契合"声音"主题**）
- **移动**：鼠标沿途漾起细小涟漪

### Q4 黄昏 `dusk`（橙）
- **画面**：底部地平线琥珀光晕（径向渐变呼吸）+ 空中漂浮尘埃颗粒（缓慢上升、布朗扰动、被光照亮）+ 轻噪点
- **视差**：光晕中心与尘埃分层偏移
- **点击**：扬起一阵尘埃扩散

### Q5 雨 `rain`（蓝）
- **粒子**：雨丝**每滴独立的长度 / 速度 / 透明度**（自然不规则 → 根治"太规则"），落到底部溅起微小水花粒子
- **斥力**：鼠标**拨开**附近雨丝（雨丝绕过鼠标，如隔着伞）
- **点击**：一片水花溅射

### Q6 月 `moon`（银）
- **画面**：银白月盘（径向渐变 + 表面微噪点暗示环形山）+ 数颗卫星粒子沿**椭圆轨道**环绕 + 外圈缓慢自转的虚线轨道
- **视差**：月盘（近）与轨道（远）分层偏移
- **点击**：月面泛起一圈光波

## 6. 交互层（统一处理）

- **pointer**：监听 `mousemove`/`touchmove`，记录归一化位置；用 **lerp 平滑跟随**避免抖动。供视差（各层按深度系数偏移）+ 斥力（效果内据 pointer 算粒子避让力）
- **click/tap**：监听后 push 一个 `ripple {x, y, t}` 进 `env.ripples`；效果内消费（波纹扩散 / 粒子爆发），消费完移除
- 交互均为"增强"，关闭交互（无鼠标/触摸）时效果仍是完整的被动动画

## 7. 变色接入

- canvas 不能直接用 CSS 变量，引擎自己持有当前 `color`（phos）/ `dim`
- `quiz.questionBackdrop(i)` 把现有 `QBG[i]` 的色值（`c[0]`/`c[1]`/`bg`）传给 `BGFX.setEffect(name, palette, tension)`
- 切题时颜色 **RGB lerp 平滑过渡**（呼应现有 `.8s` 色彩 morph 节奏）
- `tension`（题序 `i/(N-1)`，0→1）传入，效果用它调强度（粒子密度 / 速度逐题渐强），保留现有"渐强张力"设计

## 8. 降级与性能

- **`prefers-reduced-motion`**：不启动 RAF，画一帧静态（或极简渐变底），尊重用户偏好
- **可见性**：`visibilitychange` → tab 隐藏暂停 RAF，恢复继续（与现有 skipBoot 思路一致）
- **DPR**：canvas 按 `devicePixelRatio` 缩放，**上限 2**（避免 retina 过度绘制）
- **移动端/窄屏**：自动降低粒子数（按屏宽 / 触摸设备判断）
- **对象池**：粒子复用，避免每帧 GC
- **渲染门控**：仅 `body.testing` 时渲染（与现有 `#bgfx` opacity 逻辑一致）；非测试态停循环

## 9. 与现有代码的关系

- **HTML**：`<div id="bgfx">` → `<canvas id="bgfx">`（复用 id，省改动）
- **CSS**：删除 `#bgfx.fx-*`（`style.css:179-235` 的 6 段特效 + 相关 `@keyframes`）；**保留** `#bgfx` 基础定位（position/inset/z-index/opacity 过渡，174-178 行）
- **`quiz.js`**：`questionBackdrop(i)` 改为调用 `BGFX.setEffect(effectName, QBG[i], tension)`；`startTest`/`verdict` 的 `resetBackdrop()` 附带 `BGFX.reset()`
- **`terminal.js`**：启动时 `BGFX.init(canvas)`；`setBackdrop` 仍负责 body 文字色等 CSS 变量（canvas 配色单独走 BGFX）
- **新增 `assets/js/bgfx.js`**：引擎 + 6 效果 + 交互层（与现有模块化结构一脉相承，作为独立业务模块）

## 10. 验证（无自动化测试，人工浏览器走查）

- 6 道题逐一切换：每题对应效果正确、画面符合 §5 设计
- 三种交互：鼠标移动（视差）、鼠标靠近粒子（斥力/扰动）、点击（波纹/爆发）在各效果中表现正确
- 变色过渡：切题时颜色平滑 lerp、与文字色同步
- `tension`：靠后的题粒子更密/更强
- 降级：`prefers-reduced-motion` 下静态、不卡
- 性能：tab 切走暂停、移动端不卡、与 CRT 动画叠加流畅
- 回归：测试流程（boot/语言/答题/判定/命令）不受影响；控制台无报错

## 11. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 粒子数失控导致卡顿 | 粒子上限 + 移动端降级 + 实测调参；DPR 上限 2 |
| 交互手感不佳（视差过头/斥力突兀） | 参数实测微调；lerp 平滑 |
| canvas 与 CRT 多动画叠加性能 | 仅 testing 态渲染 + tab 暂停 + reduced-motion 降级 |
| 行为回归（影响测试流程） | 引擎独立模块、接口最小侵入；人工走查全流程 |
| 重构出错 | 全部工作在 `feat/canvas-bgfx` 分支，master 不受影响，可丢弃 |
